# 0.0.1 — 빈 창과 틀 (shell)

- 상태: **승인됨 (초안 7, 2026-10-25)** — PM 작성
- 요구: REQUIREMENTS.md 8절 0.0.1, R-N24(창 크기, (b) 결정 2026-10-24), R-N16(다국어), R-N18~R-N22(빌드·배포·고지), R-N1~R-N7(구조)
- 기반: BASE.md(승인본 + 2026-10-24 사실 고치기 §18)
- 그림: `specs/ui/main-screen.html`의 **틀**(다섯 영역·좌 메뉴 15개·접기). 패널 안 그림은 이 버전과 무관. **그림 자체도 승인 대상**(§10-2).
- 규격: `specs/formats/settings.md`(초안 2), `specs/formats/applog.md`(초안 2)
- 구현: GPT(Codex CLI, 이 Linux 서버). 지시서 `.pm/0.0.1/`.

## 1. 목적
저장소를 **BASE.md대로 선 구조**로 세우고, 빈 창 하나가 Windows·Linux에서 뜨며, 자동 검사와 CI가 돌아가는 것을 확인한다. 이후 모든 기능은 이 뼈대 위에 모듈로 얹힌다.

### 3.5 저장소 밖 시험이 붙는 법
- configure: `cmake --preset linux-debug -DKGC_EXTRA_TESTS_DIR=/abs/path` → 그 폴더의 `CMakeLists.txt`가 들어온다. 시험 타깃은 `kgc_composition`·`Qt6::QuickTest`에 링크.
- 조립: `QUICK_TEST_MAIN_WITH_SETUP`의 setup 객체(QGuiApplication보다 먼저 만들어지므로 생성자에서는 아무것도 안 함). **`applicationAvailable()`**(한 번): `setApplicationName("K-GroundControl")`·`setApplicationVersion(KGC_VERSION)` → `BootOptions::parse(QStringList{applicationFilePath()} + 환경 변수 KGC_TEST_ARGS를 공백으로 나눈 목록(`Qt::SkipEmptyParts`))`(QTest가 모르는 명령줄 옵션은 거부하므로 `--data-dir`·`--log-level`은 이 변수로 줌; [0]은 parse가 건너뛰는 프로그램 이름 자리) → Paths → LogSink → Settings → Translator(":/kgc/i18n")·`setLanguage(toString(settings::language()))`. **`qmlEngineAvailable(engine)`**(QML 파일마다 새 엔진): **`new Composition(*engine, AppInfo{KGC_VERSION, KGC_HOMEPAGE_URL, ":/kgc/LICENSE", KGC_TEST_NOTICES_PATH}, translator)`** — 부모가 엔진이라 파일이 끝나 엔진이 지워질 때 함께 지워짐(따로 지우지 않음; 파일마다 AppStarted…AppStopped가 순서대로 한 쌍); `loadShell()`은 부르지 않음; `KGC_TEST_NOTICES_PATH`는 시험 CMake가 `${CMAKE_BINARY_DIR}/THIRD_PARTY_NOTICES.md`로 정의. 시험 QML은 `import Kgc.Shell`하고 `Shell { id: win; visible: true }`을 직접 둔다 — 컨텍스트 프로퍼티는 엔진 뿌리에 있으므로 닿는다.
- 격리: `XDG_CONFIG_HOME`·`XDG_DATA_HOME`을 임시 폴더로.
- 화면: 이 서버의 Qt xcb 플러그인은 `libxcb-cursor.so.0`이 없어 실행이 안 된다 → **`LD_LIBRARY_PATH=~/.local/share/kgc-tools/lib`**(PM이 설치 없이 .deb를 풀어 둔 자리; §9) + `DISPLAY=:99`. 작은 화면 재현은 **`QT_SCALE_FACTOR=1.25`**(논리 1536×864).
- 시험 파일은 `.pm/tests/0.0.1/`에 보관.

## 4. 동작
1. 실행하면 창이 뜬다. 기준 1920×900(논리 픽셀); 최소 크기는 기준과 **창이 있는 화면**의 가용 영역 중 작은 쪽(화면이 바뀌면 다시 계산). 기준보다 크면 가운데가 늘어나고(uiScale 1 상한), 작은 화면(예: 1536×864)에서는 Theme 토큰이 `min(1, w/1920, h/900)` 배로 줄어 다섯 영역이 다 보인다(R-N24 (b)). 제목 "K-GroundControl 0.0.1".
2. 다섯 영역이 Theme 토큰대로 자리 잡는다. 상단바 왼쪽에 앱 아이콘(그림), 그 뒤와 오른쪽 끝에 §4-10의 상단바 자리 표시. 좌 메뉴에 §3.3 순서·구분선대로 15개.

4. ◀로 좌 메뉴가 56px(아이콘만)로 접히고 ▶로 펼쳐진다. 상태는 `shell.leftMenuCollapsed`에 저장돼 다음 실행에 유지된다.
