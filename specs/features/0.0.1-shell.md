# 0.0.1 — 빈 창과 틀 (shell)

- 상태: **초안 1 (승인 대기)** — 2026-10-24, PM 작성
- 요구: REQUIREMENTS.md 8절 0.0.1, R-N24(창 크기), R-N16(다국어), R-N18~R-N22(빌드·배포·고지), R-N1~R-N7(구조)
- 기반: BASE.md 전체(특히 §1~§3, §9.7, §14, §15)
- 그림: `specs/ui/main-screen.html`(메인 틀 — 상단바·좌 메뉴·우 사이드바·하단바·가운데 지도 자리). 이 버전에서는 **틀과 빈 자리만** 만들고, 지도·기체·메뉴 패널의 내용은 만들지 않는다.

## 1. 목적

저장소를 **BASE.md대로 선 구조**로 세우고, 빈 창 하나가 Windows·Linux에서 뜨며, 자동 검사와 CI가 돌아가는 것을 확인한다. 이 버전이 지나면 모든 기능은 이 뼈대 위에 모듈로 얹힌다.

## 4. 동작

1. 실행하면 창이 뜬다(최소 1920×900, 그보다 크면 가운데가 늘어남 — R-N24). 창 제목 "K-GroundControl 0.0.1".
2. 다섯 영역이 그림대로 자리를 잡는다. 상단바 왼쪽에 앱 아이콘(임시 글자 "K-GC"), 오른쪽은 비어 있음. 좌 메뉴에 15개가 그림 순서대로 보이고(펌웨어 세팅 ─ 기체 구성도 … 로그 분석 ─ ESC 설정 · ELRS 설정 · 안테나 트래커 ─ 수동 기체 설정 · 앱 설정), 줄 구분이 그림과 같다.
3. 메뉴를 누르면 가운데에 패널이 뜬다. 앱 설정만 내용이 있고, 나머지 14개는 "준비 중 — <제목>" 자리 표시. ✕ 또는 같은 메뉴 다시 누르기로 닫힌다.
4. ◀로 좌 메뉴가 56px(아이콘만)로 접히고 ▶로 펼쳐진다. 접힘 상태는 운영 설정 `shell.leftMenuCollapsed`에 저장돼 다음 실행에 유지된다.
5. 우 사이드바는 계기 자리 표시(240px)와 빈 탭 줄, 하단바는 빈 칩 줄. 가운데는 "지도" 자리 표시.
6. 앱 설정 패널에서 언어를 바꾸면 **재시작 없이** 모든 글자가 바뀐다(한국어 ↔ English). 시스템을 고르면 OS 언어(지원 안 하면 영어).
7. 정보 절에 버전·라이선스·고지·소스 URL이 보인다. 앱 아이콘을 눌러도 같은 곳이 열린다.
8. 실행하면 `logs/app/kgc.log`에 한국어 전보체 로그가 쌓인다("앱 시작: 0.0.1, 언어: ko", "창 표시: 1920x900").
9. 종료하면 설정이 저장되고 로그 파일이 닫힌다.

## 5. 화면 글자(원문 한국어, 영어는 `.ts`)
