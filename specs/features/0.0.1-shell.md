## 4. 동작
1. 실행하면 창이 뜬다. 최소 1920×900(논리 픽셀), 그보다 크면 가운데가 늘어난다(R-N24). 제목 "K-GroundControl 0.0.1". **§10 사용자 결정 1 참고.**
2. 다섯 영역이 Theme 토큰대로 자리 잡는다. 상단바 왼쪽에 앱 아이콘(그림), 오른쪽은 비어 있다. 좌 메뉴에 §3.3 순서·구분선대로 15개.
3. 메뉴를 누르면 가운데에 패널이 뜬다(appSettings는 내용, 나머지 14개는 "<제목> — 준비 중"). ✕ 또는 같은 메뉴를 다시 누르면 닫힌다. 다른 메뉴를 누르면 바뀐다.
4. ◀로 좌 메뉴가 56px(아이콘만)로 접히고 ▶로 펼쳐진다. 상태는 `shell.leftMenuCollapsed`에 저장돼 다음 실행에 유지된다.
5. 우 사이드바는 계기 자리(240px)와 빈 탭 줄, 하단바는 빈 칩 줄, 가운데는 "지도" 자리.
6. 앱 설정의 언어를 바꾸면 **재시작 없이** 메뉴 15개·패널·창 제목이 바뀐다. `system`은 OS 언어(지원 안 하면 영어).
7. 정보 절에 버전·GPL 전문·고지·소스 URL. 앱 아이콘을 눌러도 같은 곳.
8. 로그는 `logs/app/kgc.log`에 formats/applog 형식으로("앱 시작…", "창 표시…", "패널 열림…", "언어 변경…", "앱 종료").
9. 종료 시 설정 저장, 로그 닫힘.

## 8. 검수 안내(초안; 테스트 뒤 확정)
Windows PC: Actions → `windows.yml` 최신 실행 → zip → 풀기 → `KGroundControl.exe` → SmartScreen "추가 정보 → 실행" → 좌 메뉴 15개 눌러 보기, 접기, 앱 설정에서 English, 창 줄여 보기(1920×900 아래로 안 됨). **화면이 1920×1080에 125% 배율이면 창이 화면보다 커질 수 있음 — §10 결정 1.**

## 9. 알려진 환경 사실(이 서버)
