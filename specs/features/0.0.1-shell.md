- 상태: **초안 3 (검토 2 반영, 승인 대기)** — 2026-10-24, PM 작성
- 요구: REQUIREMENTS.md 8절 0.0.1, R-N24(창 크기), R-N16(다국어), R-N18~R-N22(빌드·배포·고지), R-N1~R-N7(구조)

## 1. 목적
저장소를 **BASE.md대로 선 구조**로 세우고, 빈 창 하나가 Windows·Linux에서 뜨며, 자동 검사와 CI가 돌아가는 것을 확인한다. 이후 모든 기능은 이 뼈대 위에 모듈로 얹힌다.

### 3.5 저장소 밖 시험이 붙는 법
`cmake --preset linux-debug -DKGC_EXTRA_TESTS_DIR=/abs/path`로 그 폴더의 `CMakeLists.txt`가 들어온다. 시험은 `kgc_composition`과 `Qt6::QuickTest`에 링크하고 `QUICK_TEST_MAIN_WITH_SETUP`의 setup에서 main.cpp와 같은 순서로 조립한다. 설정·데이터는 `XDG_CONFIG_HOME`·`XDG_DATA_HOME`(또는 `--data-dir`)을 임시 폴더로 줘 격리한다. 시험 파일은 `.pm/tests/0.0.1/`에 보관.

## 4. 동작
1. 실행하면 창이 뜬다. 최소 1920×900(논리 픽셀), 그보다 크면 가운데가 늘어난다(R-N24). 제목 "K-GroundControl 0.0.1". **§10-1 결정에 따라 바뀔 수 있음.**
2. 다섯 영역이 Theme 토큰대로 자리 잡는다. 상단바 왼쪽에 앱 아이콘(그림), 오른쪽은 비어 있다. 좌 메뉴에 §3.3 순서·구분선대로 15개.
3. 메뉴를 누르면 가운데에 패널이 뜬다(appSettings는 내용, 나머지 14개는 "<제목>" + "준비 중"). ✕ 또는 같은 메뉴를 다시 누르면 닫힌다. 다른 메뉴를 누르면 바뀐다.
4. ◀로 좌 메뉴가 56px(아이콘만)로 접히고 ▶로 펼쳐진다. 상태는 `shell.leftMenuCollapsed`에 저장돼 다음 실행에 유지된다.
5. 우 사이드바는 계기 자리(240px)와 빈 탭 줄, 하단바는 빈 칩 줄, 가운데는 "지도" 자리.
6. 앱 설정의 언어를 바꾸면 **재시작 없이** 메뉴 15개·패널·창 제목이 바뀐다. `system`은 OS 언어(ko·en 밖이면 en).
7. 정보 절에 버전·GPL 전문·고지·소스 URL. 앱 아이콘을 눌러도 같은 곳(정보 절로 스크롤).
8. 로그는 `logs/app/kgc.log`에 formats/applog 형식("앱 시작…", "창 표시…", "패널 열림…", "언어 변경…", "앱 종료").
9. 종료 시 설정 저장, 로그 닫힘.
