### 3.2 테마 목록과 고르는 판정
| id | order | 이름(문맥 `Theme`, 원문 → 영어) | 바탕 | 유리 |
|---|---|---|---|---|
| `light` | 10 | 라이트 → Light | 밝음 | 아님 |
| `dark` | 20 | 다크 → Dark | 어두움 | 아님 |
| `aeroLight` | 30 | 에어로 라이트 → Aero Light | 밝음 | **유리** |
| `aeroDark` | 40 | 에어로 다크 → Aero Dark | 어두움 | **유리** |

- 설정 **`ui.theme`**(정의 `platform/ui/internal/settings/ui.settings.json`, type `string`, default `"system"`, category `ui`, labelKey "테마"). 값은 테마 id 또는 `system`.
- **판정은 순수 함수 하나**(`api/kgc/ui/ThemeChoice.h`): `ThemeChoice resolveTheme(QStringView selected, Qt::ColorScheme scheme, const QStringList& available)`. `ThemeChoice{QString id; ThemeReason reason}`, `enum class ThemeReason{Setting, System, Unknown}`.
  - `selected`가 `available`에 있으면 → `{selected, Setting}`.
  - `selected == "system"` → `scheme == Dark`면 `{"dark", System}`, 아니면(`Light`·`Unknown`) `{"light", System}`.
  - 그 밖(목록에 없는 id) → system과 같은 판정, reason `Unknown`.
  - 에어로는 system 판정에서 나오지 않는다.
- 사용자가 고르면 그 id가 저장되고 이후 OS 모드와 상관없다. 콤보에는 네 테마만 나온다(`system`은 항목이 아님). 값이 `system`인 동안 콤보는 적용된 테마를 보여 준다.
- 전환은 재시작 없이 즉시.

### 3.3 테마 파일과 토큰 (테마 추가 = 파일 하나)
- `ThemeBase.qml`(뿌리 `QtObject`): 아래 토큰을 **`required property`**로 선언한다. 테마 파일 `themes/<Name>.qml`은 `ThemeBase { … }` 하나이며 모든 토큰에 값을 준다. 테마 파일은 색 리터럴이 허용되는 자리다(§3.6).
- 목록: `ThemeSwitcher`가 QML 모듈 자원 폴더 `:/qt/qml/Kgc/Ui/themes/`에서 `ThemeBase.qml` 밖의 `*.qml`을 읽는다. id = 파일 이름의 첫 글자를 소문자로(`AeroDark.qml` → `aeroDark`). 순서 = `order` 오름차순, 같으면 id 순. CMake는 `themes/*.qml`을 `file(GLOB CONFIGURE_DEPENDS)`로 QML 모듈에 넣고, 이 파일들(`ThemeBase.qml` 포함)에 **`QT_QML_INTERNAL_TYPE TRUE`**를 준다 — 모듈 밖 화면이 테마 객체를 직접 만들지 못하고(주인 하나), `QtQuick3D`의 `Light`와 이름이 겹치지 않게. **새 테마 = `themes/<Name>.qml` 파일 하나**(다른 코드는 고치지 않음). 영어 이름은 `.ts`에 더하면 나오고, 없으면 원문이 보인다.
- 토큰 이름은 `on` + 대문자로 시작하지 않는다(QML이 `onX`를 시그널 처리기로 읽음 — 0.0.2 구현 2회차에서 확인). 그래서 강조·위험 바탕 위 글자는 `accentInk`·`dangerInk`.
- 검사 `theme_tokens`(Qt 없이): `ThemeBase.qml`의 required 이름 목록과 각 테마 파일이 값을 준 이름이 정확히 같아야 한다(빠짐·남음 모두 실패, 규칙 이름 출력, 종료 1).

| 묶음 | 토큰(형) |
|---|---|
| 이름·순서 | `titleKey`(string, `QT_TRANSLATE_NOOP("Theme", "…")`), `order`(int), `dark`(bool), `glass`(bool) |
| 바탕 | `window`, `region`, `surface`, `surfaceAlt`, `overlay` (color; 알파 가능) |
| 글자 | `ink`, `inkMuted`, `inkInverse`, `inkDisabled` (color) |
| 선 | `line`, `lineStrong`, `focus` (color) |
| 강조 | `accent`, `accentHover`, `accentPressed`, `accentInk`, `dangerInk` (color) |
| 상태 | `ok`, `warn`, `danger`, `info`, `idle`, `okSoft`, `warnSoft`, `dangerSoft`, `infoSoft` (color) |
| 유리 | `glassTint`(color, 알파), `glassBlur`(real 0~1, MultiEffect `blur`), `glassBlurMax`(int, `blurMax`), `glassEdge`(color, 위쪽 밝은 테두리), `glassShine`(real 0~1, 위→아래 광택). 유리 아닌 테마는 `glassBlur 0`·`glassShine 0` |
| 지도 자리 무늬 | `mapPatternA`, `mapPatternB` (color; 지도가 들어오기 전 시험 무늬 두 색) |
| 차트 | `series1` … `series6`(color; 선·막대·조각 순서 색), `chartGrid`, `chartAxis` (color) |
| 모양 | `radiusSmall`, `radiusMedium`, `radiusLarge`(int, 배율 전), `shadow`(bool), `shadowColor`(color) |
| 글꼴 | `fontFamily`, `monoFamily` (string) |

- `Theme.qml`: 0.0.1 크기 토큰은 그대로, `property ThemeBase current: Light {}`(처음 값 — 빈 값이 없게), 위 토큰을 `readonly property color window: current.window` 꼴로 다시 내놓는다(모양 크기는 `uiScale`을 곱함). 부품·화면은 `Theme.<토큰>`만 쓰고 `Theme.current`를 직접 읽지 않는다.
- **부품 크기 토큰**: 부품이 쓰는 크기(입력란 너비, 컨트롤 높이, 차트·계기 크기, 표 줄 높이 등)는 `Theme.qml`에 쓰임을 드러내는 이름으로 더한다(이름은 구현자가 정하고 `Theme.qml`에 한 줄 주석; 모두 `Math.round(<값> * uiScale)` 꼴, 모양 반지름도 같은 꼴). 부품은 0.0.1 shell 배치 토큰(`languageWidth`, `instrumentHeight`, `menuHeight`, `menuGap` 등)을 빌려 쓰지 않는다.
- **차트 색 묶음**: `Theme.qml`이 `readonly property list<color> seriesColors: [series1 … series6]`을 내놓고, 차트 셋은 `components/ChartTheme.qml`(QML 내부 형, `GraphsTheme` 하나를 Theme 토큰에 묶음)을 함께 쓴다. 테마가 바뀌어도(재시작 없이) 격자·축·글자 색이 Theme 토큰을 따라야 한다.
- **0.0.1 색 이름 바꿈**: `background` → `window`, `dim` → `inkMuted`(별칭 두지 않음, 쓰는 곳을 고침). `region`·`surface`·`line`·`ink`·`accent`는 그대로.

### 3.5 부품 (`platform/ui/components/`, `import Kgc.Ui`)
모든 부품은 `QtQuick.Templates`(또는 `QtQuick.Controls.Basic`) 위에 우리가 그린다. 차트 셋(`LineChart`·`BarChart`·`PieChart`)은 Qt Graphs를 감싸고, 그 `GraphsTheme`(배경 없음, `seriesColors`, 격자·축·글자 색)을 Theme 토큰에 묶는다. 크기·색은 Theme 토큰만. 상태: 기본·올림·누름·비활성·초점을 테마마다 구분해 보인다. 초점은 `Theme.focus` 색 테두리. 버튼류는 Space와 Enter·Return 모두로 누른다(Enter는 부품이 따로 받음). 갤러리에서 objectName은 `gallery_<부품>`(변형이 여럿이면 `gallery_<부품>_<변형>`). **부품 이름(표의 둘째 칸)과 이 표·§3.4가 적은 속성만 고정**이다; 그 밖의 부품 안 공개 속성·함수·시그널 이름은 구현자가 Qt Controls 관례(`text`, `checked`, `value`, `from`/`to`, `clicked()` 등)를 따라 정하고, 각 부품 파일 머리 docstring에 적는다(새 낱말 보고 대상 아님).

### 3.6 새 검사 `qml_literal` (BASE §6을 0.0.2부터 적용)
QML 파일 한 줄씩 본다(Qt 없이).
- **크기**: 속성 이름이 {`width`, `height`, `implicitWidth`, `implicitHeight`, `padding`, `*Padding`, `margins`, `*Margin`, `spacing`, `radius`} 중 하나이고(앞에 `객체.`가 붙어도 마지막 이름으로 본다: `background.implicitWidth: 13`·`border.width: 2`도 잡힘), **값 전체가** 부호를 포함한 0 아닌 숫자 리터럴 하나일 때만 잡는다. 식 안의 리터럴(`radius: height / 2`, `width: parent.width / 2`)은 대상이 아니다.
- **색**: 값에 `"#` 로 시작하는 문자열, `Qt.rgba(`·`Qt.hsla(`·`Qt.hsva(`, 또는 CSS 색 이름 문자열(`"red"`, `"white"` …)이 있으면 잡는다. **`"transparent"`는 허용**.
- 허용 자리: `src/platform/ui/Theme.qml`, `src/platform/ui/themes/`. `anchors.`로 시작하는 속성(`anchors.margins` 등)·`z`·`opacity`는 대상 아님(BASE §6).
- 0.0.1 QML이 이 검사를 통과하도록 고친다.

### 3.11 검수 중 사용자 요청(2026-10-25): 배경 · 설정 화면 배치 · 차트 선명도
**(가) 배경** — 가운데 바닥(`mapStage`)의 그림을 고른다(지도가 들어오기 전까지의 바탕; 유리 테마는 이것이 흐리게 비침).
- 설정 `ui.backgroundKind`(enum `plain`·`checker`·`image`, default `checker`, category `ui`, labelKey "배경"), `ui.backgroundImage`(string, default `""`, labelKey "배경 사진"; 사진 파일의 절대 경로).
- `plain` = `Theme.window` 단색. `checker` = 지금의 시험 무늬(`mapPatternA`·`B` 격자). `image` = 그 파일을 `mapStage`에 채워 그림(가로세로 비율 유지, 넘치는 부분 자름 = `PreserveAspectCrop`). PNG·JPEG.
- 사진을 못 읽으면(없음·형식 아님) `plain`으로 그리고 WARN `ui.BackgroundImageMissing`("배경 사진 못 읽음: <경로>", 경로 값마다 한 번).
- `UiSettingValues`가 Q_PROPERTY `backgroundKind`·`backgroundImage`(읽기·쓰기)와 `backgroundKinds`(생성 `backgroundKindValues()`)를 낸다. 그리는 것은 shell(`mapStage` 안 `backgroundLayer`, 새 objectName).
- 앱 설정 "화면" 칸: `backgroundKindPicker`(PillGroup: 민무늬·체크무늬·사진), `backgroundImageField`(FileField; 찾아보기는 `QtQuick.Dialogs`의 `FileDialog`, 거르기 "사진 (*.png *.jpg *.jpeg)"; 사진을 고르면 kind가 `image`가 됨).
- 테마와 별개다(테마를 바꿔도 배경 설정은 그대로).

**(나) 설정 화면 배치** — 설정 패널은 **왼쪽 카테고리 : 오른쪽 항목 = 1 : 3** 너비(패널 안쪽 너비 기준, 창 크기가 바뀌어도 비율 유지).
- 공용 부품 `SettingsPage`(`platform/ui/components/`, §3.5에 더함): 왼쪽 `settingsCategoryList`(카테고리 이름 목록, 고른 것 강조, 키보드 ↑/↓), 오른쪽 `settingsContent`(고른 카테고리의 `Section`들이 세로로 놓이고 스크롤). 카테고리 항목 objectName `settingsCategory_<id>`. 이후 설정 패널(기능 패널의 설정 화면)도 이 부품을 쓴다.
- 앱 설정 카테고리(순서·id·이름): `general` 일반(언어) · `display` 화면(테마, 배경) · `input` 조작(길게 눌러 확인 시간) · `about` 정보(버전·라이선스·고지·소스). 0.0.1·0.0.2의 objectName(`languageCombo`, `themeCombo`, `holdTimeField`, `aboutVersion` …)은 그대로.
- `Navigator.open("appSettings","about")`(앱 아이콘)은 `about` 카테고리를 고른 채 연다.

**(다) 차트 선명도** — 선·곡선이 계단처럼 보이지 않게 한다.
- `main.cpp`(와 시험 setup)가 창을 만들기 전에 `QSurfaceFormat::setDefaultFormat`으로 **멀티샘플 4**를 켠다(RHI가 OpenGL·Direct3D 모두에서 MSAA).
- 직접 그린 도형(`RingGauge`·`ArcGauge`·`Sparkline` 등 `QtQuick.Shapes`)은 `preferredRendererType: Shape.CurveRenderer`.
- 차트 선 굵기·축 글자 크기는 Theme 토큰(`uiScale` 반영)에서; 1px 고정 선 없음.

## 4. 동작
1. 처음 실행(설정 없음): OS가 다크면 다크, 아니면 라이트. 앱 설정의 `themeCombo`는 적용된 테마를 보여 준다.
2. 앱 설정에서 테마를 고르면 즉시 바뀌고 저장된다. 재실행해도 유지. 갤러리의 빠른 전환 줄도 같은 설정을 바꾼다.
3. **층 구조**(모든 테마 공통): `centerArea` 안에 바닥 층 **`mapStage`**(새 objectName; `mapPlaceholder`와 `MapLayerSlot` 내용을 담음), 그 위 형제로 **`centerViewport`**(새 objectName; 바에 가리지 않는 안쪽 영역 — 지도 자리 글자와 `panelOverlay`가 이 안에 놓임).
   - **유리 아닌 테마**: 0.0.1 배치 그대로(바와 가운데가 나란히). `centerArea` = `mapStage` = `centerViewport` 크기.
   - **유리 테마**: `centerArea`와 `mapStage`가 창 전체를 덮고, 네 바는 같은 자리·같은 크기로 그 위에 겹친다. `centerViewport`는 네 바를 뺀 안쪽(0.0.1의 가운데 자리와 같은 크기). 각 바와 `panelOverlay`의 바탕은 `GlassSurface`(source = `mapStage`)라 지도 자리만 흐리게 비친다(패널끼리·바끼리는 비치지 않음). **패널 계약**: 등록된 패널 컴포넌트의 뿌리에 `property Item glassSource`가 있으면 shell이 불러온 뒤 `mapStage`를 넣는다(패널 안 `Card`·`GlassSurface`는 이것을 source로 씀). 다른 이름(`source` 등)으로 몰래 넣지 않는다. shell MODULE.md '주는 것'에 적는다.
   - `mapPlaceholder`는 이 버전에서 시험 무늬(`mapPatternA`·`mapPatternB`의 24px 격자 + 글자 "지도")를 그린다.
4. 좌 메뉴 맨 아래(구분선 뒤)에 **UI 부품 목록**. 누르면 부품 전체가 부문별(버튼·고르기·입력·표시·묶음·알림·차트)로 나오고 세로로 스크롤된다. 각 부품은 변형과 상태(기본·비활성·오류 등)를 나란히 보인다.
5. HoldToConfirm: 갤러리는 확인되면 옆에 "확인됨" 글자를 2초 띄운다(TimerBox).
6. 키보드: 갤러리를 열면 첫 초점은 `galleryThemeSwitch`; Tab으로 부품 사이를 움직이면 초점 테두리가 보인다. Space·Enter로 버튼·토글을 누른다.
7. 0.0.1 화면(좌 메뉴·접기·패널 닫기·앱 설정·정보 창)도 테마를 따른다.

## 9. 알려진 환경 사실 (2026-10-25 실측)

Tabler SVG(`currentColor`)를 `Image`+`MultiEffect`(`colorization 1`)와 Basic 스타일 `Button`의 `icon.color`로 그리면 준 색으로 칠해진다(같은 날 실측; SVG는 `Qt6::Svg` 필요).

- `:99` 기본: `colorScheme()==Unknown`, `setColorScheme`이 무시됨. **`XDG_CURRENT_DESKTOP=GNOME`**: 처음 `Light`, `setColorScheme(Dark)`·`(Light)`가 먹고 `colorSchemeChanged` 나옴.
