## 1. 목적
화면의 색·모양을 **테마 파일**로 갈아 끼울 수 있게 하고(라이트·다크·에어로 라이트·에어로 다크), 이후 모든 기능 화면이 쓸 **공용 UI 부품**을 `Kgc.Ui`에 한 번에 갖춘다. 개발 단계에서 부품을 눈으로 확인하도록 좌 메뉴에 **UI 부품 목록** 패널을 둔다.

### 3.2 테마 목록과 고르는 법
| id | 이름(원문 → 영어) | 바탕 | 유리(glass) |
|---|---|---|---|
| `light` | 라이트 → Light | 밝음 | 아님 |
| `dark` | 다크 → Dark | 어두움 | 아님 |
| `aeroLight` | 에어로 라이트 → Aero Light | 밝음 | **유리** |
| `aeroDark` | 에어로 다크 → Aero Dark | 어두움 | **유리** |

- 설정 **`ui.theme`**(`platform/ui`, type `string`, default `"system"`, category `ui`, labelKey "테마"). 값은 테마 id 또는 `system`.
- `system`(처음 실행, 사용자가 아직 고르지 않음): OS 색 모드를 따른다 — `QStyleHints::colorScheme()`이 `Dark`면 `dark`, `Light`·`Unknown`이면 `light`. OS 모드가 실행 중에 바뀌면(`colorSchemeChanged`) 바로 따라간다. 에어로는 OS를 따라 고르지 않는다.
- 사용자가 콤보에서 하나를 고르면 그 id가 저장되고, 이후 OS 모드와 상관없이 그대로다. 콤보에는 네 테마만 나온다(`system`은 항목이 아님). 값이 `system`인 동안 콤보는 적용된 테마를 보여 준다.
- 저장된 id가 테마 목록에 없으면(파일을 지운 경우) `system`처럼 동작하고 WARN 로그 `ThemeUnknown`.
- 전환은 재시작 없이 즉시. 언어 전환과 같이 화면 전체가 다시 그려진다.

### 3.3 테마 파일과 토큰 (테마 추가 = 파일 하나)
- `ThemeBase.qml`(뿌리 `QtObject`): 아래 토큰을 **`required property`**로 선언한다. 테마 파일은 `ThemeBase { … }` 하나이며 모든 토큰에 값을 준다.
- 목록: `ThemeController`가 QML 모듈 자원의 `themes/` 폴더를 읽어 `ThemeBase.qml` 밖의 `*.qml`을 테마로 본다(파일 이름 첫 글자를 소문자로 = id). CMake는 `themes/*.qml`을 `file(GLOB CONFIGURE_DEPENDS)`로 모듈에 넣는다. **새 테마 = `themes/<Name>.qml` 파일 하나 + 번역 한 줄**, 다른 코드는 고치지 않는다.
- 검사 `theme_tokens`(Qt 없이): `ThemeBase.qml`의 required 이름 목록과 각 테마 파일이 값을 준 이름이 정확히 같아야 한다(빠짐·남음 모두 실패). 테마 파일에는 색 리터럴이 허용된다(`qml_literal` 류 검사의 허용 자리에 `themes/`를 더함 — BASE §6 고침, §11).

| 묶음 | 토큰(형) |
|---|---|
| 이름 | `titleKey`(string, `QT_TR_NOOP`), `dark`(bool), `glass`(bool) |
| 바탕 | `window`, `region`, `surface`, `surfaceAlt`, `overlay`(패널이 지도 위에 뜰 때 뒤를 가리는 색, 알파 포함) (color) |
| 글자 | `ink`, `inkMuted`, `inkInverse`, `inkDisabled` (color) |
| 선 | `line`, `lineStrong`, `focus` (color) |
| 강조 | `accent`, `accentHover`, `accentPressed`, `onAccent`, `onDanger`(danger 바탕 위 글자) (color) |
| 상태 | `ok`, `warn`, `danger`, `info`, `idle` + 각각의 옅은 바탕 `okSoft`, `warnSoft`, `dangerSoft`, `infoSoft` (color) |
| 유리 | `glassTint`(color, 알파 포함), `glassBlur`(real 0~1, MultiEffect `blur`), `glassBlurMax`(int, MultiEffect `blurMax`), `glassEdge`(color; 위쪽 밝은 테두리), `glassShine`(real 0~1; 위→아래 광택 세기). 유리 아닌 테마는 `glassBlur 0`, `glassShine 0` |
| 모양 | `radiusSmall`, `radiusMedium`, `radiusLarge`(int, 배율 전 값), `shadow`(bool), `shadowColor`(color) |
| 글꼴 | `fontFamily`(string), `monoFamily`(string) |

- `Theme.qml`은 크기 토큰(0.0.1)을 그대로 갖고, 위 토큰을 `readonly property color window: current.window` 꼴로 다시 내놓는다(부품·화면은 `Theme.<토큰>`만 쓴다; `Theme.current`를 직접 읽지 않음). 모양 크기는 Theme가 `uiScale`을 곱해 준다.
- `Theme.current`의 주인은 `ThemeController` 하나. 다른 코드는 읽기만.

### 3.7 시험 붙이는 법·실행 환경
- 0.0.1 §3.5 그대로(`-DKGC_EXTRA_TESTS_DIR`, `QUICK_TEST_MAIN_WITH_SETUP`, `KGC_TEST_ARGS`, `XDG_*` 격리, `DISPLAY=:99`, `LD_LIBRARY_PATH=~/.local/share/kgc-tools/lib`). setup의 `qmlEngineAvailable`이 만드는 `Composition`이 `ThemeController`도 만든다.
- OS 색 모드 흉내: 시험은 `QGuiApplication::styleHints()->setColorScheme(Qt::ColorScheme::Dark/Light)`로 바꾼다(Qt 6.8+, 헤더 `qstylehints.h` 확인). `:99`(Xvfb)에서 그냥 실행하면 `Unknown`.
- 흐림 확인: `grabToImage`로 바 영역을 찍어, 유리 테마에서는 뒤 무늬(§4-3의 시험 무늬)가 흐려져 비치고(픽셀 값이 무늬 두 색 사이), 유리 아닌 테마에서는 `surface` 단색인지 본다.
- 시험 파일은 `.pm/tests/0.0.2/`에 보관.

## 4. 동작
1. 처음 실행(설정 없음): OS가 다크면 다크, 아니면 라이트로 뜬다. 앱 설정의 `themeCombo`는 적용된 테마를 보여 준다.
2. 앱 설정에서 테마를 고르면 즉시 바뀌고 저장된다. 재실행해도 유지된다. 갤러리의 빠른 전환 줄도 같은 설정을 바꾼다.
3. **유리 테마 배치**: `Theme.glass`가 참이면 가운데(`centerArea`)가 창 전체를 덮고, 상단바·좌 메뉴·우 사이드바·하단바는 그 위에 같은 자리·같은 크기로 겹쳐 뜬다. 각 바의 바탕은 `GlassSurface`(원본 = `centerArea`)라 뒤의 지도 자리가 흐리게 비친다. 지도 자리 표시(`mapPlaceholder`)는 이 버전에서 **시험 무늬**(Theme 색 두 개의 격자 + 글자 "지도")를 그려 흐림이 보이게 한다. 유리 아닌 테마는 0.0.1 배치 그대로(나란히).
   - 유리 배치에서 `centerArea`의 크기는 창 크기와 같다. 지도 자리 글자·패널(`panelOverlay`)은 바에 가리지 않는 안쪽 영역 `centerViewport`(새 objectName)의 가운데에 둔다.
4. 패널(`panelOverlay`)도 유리 테마에서는 `GlassSurface` 바탕.
5. 좌 메뉴 맨 아래(구분선 뒤)에 **UI 부품 목록**. 누르면 부품 전체가 부문별(버튼·고르기·입력·표시·묶음·알림)로 나오고 세로로 스크롤된다. 각 부품은 쓸 수 있는 변형과 상태(기본·비활성·오류 등)를 나란히 보여 준다.
6. HoldToConfirm: 누르고 있으면 막대가 `ui.holdToConfirmMs` 동안 찬 뒤 `confirmed()` 한 번; 그 전에 떼면 비워지고 아무 일도 없다. 갤러리는 확인되면 옆에 "확인됨" 글자를 2초 띄운다(TimerBox).
7. 키보드: Tab으로 부품 사이를 움직이면 초점 테두리(`focus` 색)가 보인다. Space/Enter로 버튼·토글을 누른다.
