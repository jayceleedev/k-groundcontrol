### 3.2 하단바 맨 오른쪽 단추
- 새 슬롯 **`BottomActionSlot`**(`platform/ui`, `SlotModel` 바탕): 하단바 **맨 오른쪽**에 놓이는 단추 기여(항목: id, order, icon, hintKey, `trigger` 시그널을 낼 QML 또는 C++ 호출). shell `BottomBar.qml`은 왼쪽에 `StatusChipSlot`, 맨 오른쪽에 `BottomActionSlot`을 order 순으로 그린다.
- 기여: `secondPanel`(order 10, icon `layout-dashboard`, 힌트 "세컨드 패널"), `analyze`(order 20, icon `logs`, 힌트 "앱 로그"). 순서는 왼쪽부터 세컨드 패널, 로그(로그가 맨 끝). objectName `bottomAction_secondPanel`, `bottomAction_appLog`. 모양은 `IconButton`.
- 누르면 그 모듈의 창이 열린다. 이미 열려 있으면 앞으로 가져온다(새로 만들지 않음). 다시 눌러 닫지는 않는다(창의 닫기 단추로 닫음).

### 3.3 앱 로그를 화면에 넘기는 통로 — `LogFeed`(`platform/app/log`)
- `LogFeed`(QObject, 전역 하나, `LogSink`가 소유): `LogSink`가 파일에 쓰는 **같은 줄**(formats/applog 꼴 문자열)을 시그널 `lineWritten(QString)`으로 GUI 스레드에 queued로 낸다. 최근 **2000줄**을 고리 버퍼로 들고 `recent()`로 준다(창을 늦게 열어도 앞부분이 보이게). 줄 수는 `internal/Constants.h`.
- 다른 모듈은 `LogFeed`만 읽는다(파일을 다시 읽거나 꼬리를 따라가지 않음).

### 3.4 창 자리 기억 — `WindowPlacement`(`platform/ui`)
- 순수 함수 `QRect restorePlacement(const QString& saved, const QList<ScreenInfo>& screens, QSize defaultSize)`와 `QString savePlacement(const QString& screenName, QRect geometry)`. 저장 꼴: `"<화면 이름>|x|y|w|h"`(논리 픽셀). `ScreenInfo{name, availableGeometry}`.
  - 저장한 화면이 지금 있으면 그 화면 안에서 같은 자리·크기(화면 밖으로 나가면 화면 안으로 옮기고, 화면보다 크면 줄임).
  - 저장한 화면이 없거나 저장값이 비었거나 깨졌으면 **주 화면** 가운데에 `defaultSize`.
- 창(QML `Window`)은 열 때 이것으로 자리를 정하고, 옮기거나 크기를 바꾸면 저장한다(저장은 움직임이 멎은 뒤 한 번 — TimerBox 500ms). 화면 정보는 `Qt.application.screens`/`QGuiApplication::screens()`.

### 3.8 세컨드 패널 배치 틀(최대 6칸)
순수 함수 `QList<QRectF> cellRects(LayoutId)`(`internal/SecondPanelLayout`, 0~1 비율 좌표, 칸 사이 간격은 QML이 `Theme.inset`으로) — `tests/test_second_panel_layout.cpp`가 본다.

| id | 이름(원문 → 영어) | 칸 | 배치 |
|---|---|---|---|
| `single` | 1칸 → 1 | 1 | 전체 |
| `split2h` | 2칸 좌우 → 2 side by side | 2 | 왼·오른 절반 |
| `split2v` | 2칸 위아래 → 2 stacked | 2 | 위·아래 절반 |
| `main3` | 3칸(큰 칸 + 둘) → 3 (1 large + 2) | 3 | 왼쪽 2/3 큰 칸 1, 오른쪽 1/3을 위·아래 둘 |
| `grid2x2` | 4칸 → 4 | 4 | 2×2 |
| `grid3x2` | 6칸 가로 → 6 (3×2) | 6 | 가로 3 × 세로 2 |
| `grid2x3` | 6칸 세로 → 6 (2×3) | 6 | 가로 2 × 세로 3 |

칸 번호는 왼쪽 위부터 가로로(`main3`은 큰 칸이 1). 바꾸면 즉시 다시 배치되고 저장된다.

## 4. 동작
1. 하단바 맨 오른쪽에 단추 둘(세컨드 패널, 앱 로그). 마우스를 올리면 힌트.
2. **앱 로그**를 누르면 별도 창이 열리고, 지금까지의 최근 줄(최대 2000)이 보인 뒤 새 줄이 생길 때마다 아래에 붙으며 끝으로 따라간다. 위로 올리면 멈춤, 맨 아래로 내리거나 `followToggle`을 켜면 다시 따라감. 수준별 색(WARN `warn`, ERROR `danger`, DEBUG `inkMuted`).
3. **세컨드 패널**을 누르면 별도 창이 열리고, 고른 배치의 빈 칸들이 보인다. 위 줄에서 배치를 바꾸면 즉시 바뀌고 다음에도 그 배치.
4. 두 창 모두 마지막 자리·크기·모니터로 다시 열린다(모니터가 없어졌으면 주 화면 가운데). 메인 창을 닫으면(앱 종료) 두 창도 닫힌다. 다음 실행 때 저절로 열리지는 않는다.
5. 두 창은 메인 창과 같은 테마·언어를 따르고, 바꾸면 바로 바뀐다. 유리 테마에서 창 바탕은 `window` 단색(지도 바닥이 없으므로).
