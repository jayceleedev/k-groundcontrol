### 3.2 우 탭 슬롯 — `RightTabSlot` 등록
- `Result<void> registerTab(const QString& id, int order, const QString& titleKey, const QUrl& component, RightTabPlacement placement)` — `SlotModel::add`를 쓴다(order 정렬, 같은 id면 `UiError::DuplicateId`).
- `enum class RightTabPlacement { Top, Tab }`(`Slots.h`). `Top`은 탭 줄 위 계기 칸(높이 `Theme.instrumentHeight`)에 들어가는 항목이고 **하나만** 둘 수 있다: 이미 `Top`이 있는데 또 오면 `UiError::DuplicateId`가 아니라 새 오류 `UiError::TopTaken`(`Errors.h`, `errorText` 원문 "우 사이드바 계기 자리는 하나만 쓸 수 있어요."). `Tab`은 탭 줄의 탭 하나.
- 역할: `id`·`order`(공통) + `titleKey`(번역 문맥 **"RightTab"**의 한국어 원문, 등록하는 쪽은 `QT_TRANSLATE_NOOP("RightTab", "…")`)·`component`(QML URL)·`placement`(문자열 `"top"`|`"tab"`).
- 기여(BASE §9.8 순서):

| id | 모듈 | placement | order | 이름 원문 → 영어 |
|---|---|---|---|---|
| `instrument` | vehicleInfo | Top | 0 | 계기 → Instrument(탭 줄에는 안 보임) |
| `overview` | vehicleInfo | Tab | 10 | 개요 → Overview |
| `detail` | vehicleInfo | Tab | 20 | 상세 → Details |
| `messages` | vehicleInfo | Tab | 30 | 메시지 → Messages |
| `logs` | logs | Tab | 40 | 로그 → Logs |
| `preflight` | preflight | Tab | 50 | 점검 → Checklist |

### 3.3 계기 부품 — `AttitudeIndicator`(`platform/ui` components)
- 공용 부품으로 둔다(세컨드 패널 칸에서 다시 쓸 것을 염두 — 사용자 결정 §10-4). 속성 `roll`·`pitch`(도), `heading`(도, 0~360), `available`(bool, 기본 거짓).
- `available`이 참이면: 원 안에 하늘·땅 두 색과 수평선을 `roll`만큼 돌리고 `pitch`만큼 옮겨 그린다(눈금: pitch ±10°·±20°, roll 0·±30·±60). 가운데 고정 기체 표시. 아래에 헤딩 `"%1°"`(정수, 3자리 0 채움 없이).
- `available`이 거짓이면: 수평선을 0°로, 하늘·땅을 둘 다 `surfaceAlt` 한 색으로 흐리게 그리고, 가운데 아래 글자 **"기체 없음"**(`inkMuted`), 헤딩 자리는 **"---°"**.
- 색 토큰 **`attitudeSky`·`attitudeGround`**를 `ThemeBase.qml`(required)과 네 테마 파일에 더한다(검사 `theme_tokens`). 크기 토큰은 `Theme.qml`에 이름으로(0.0.2 §3.5 규칙). 그림은 Shape `CurveRenderer`(0.0.2 T26과 같은 선명도 규칙).
- UI 부품 목록(uiGallery)에 견본: `available` 토글과 roll·pitch·heading 슬라이더.

### 3.4 빈 상태 부품 — `EmptyState`(`platform/ui` components)
- 영역 가운데에 제목 한 줄과 설명 한 줄(둘 다 `inkMuted`, 제목은 `fontSize`, 설명은 작은 글꼴 토큰), 테두리 점선 `line`. 속성 `title`·`detail`. 누를 것 없음. uiGallery에 견본.

### 3.5 셸 — `RightBar.qml`
- 맨 위 계기 칸 `rightTop`(높이 `Theme.instrumentHeight`, 바깥 여백 `Theme.inset`): `placement=="top"` 항목의 `component`를 `Loader`로 싣는다. 없으면 지금처럼 빈 상자.
- 그 아래 탭 줄 `rightTabs`(높이 `Theme.rightTabHeight`): `TabStrip`, `placement=="tab"` 항목을 order 순서로, 이름은 `qsTranslate("RightTab", titleKey)`(`Translator.language`에 다시 묶음). 탭 단추 objectName **`rightTab_<id>`**. 처음 고른 탭 = order가 가장 작은 탭(개요). 고른 탭은 기억하지 않는다(다음 실행엔 다시 개요).
- 그 아래 내용 칸 `rightTabContent`: 고른 탭의 `component`를 `Loader`로 싣고, 내용이 칸보다 길면 **세로로 스크롤**(가로 스크롤 없음). 탭을 바꾸면 새 탭이 맨 위에서 시작.
- shell은 `RightTabPlacement`·탭 id를 모른 채 역할 값만 읽는다(잎 모듈).

## 4. 동작
1. 우 사이드바 맨 위에 계기: 회색 원과 수평선, "기체 없음", 헤딩 "---°".
2. 그 아래 탭 줄 개요·상세·메시지·로그·점검, 처음엔 개요.
3. 탭을 누르면 그 탭 화면. 모든 탭은 "기체 없음" 모습이고, 탭 바꾸기 말고는 누를 수 있는 것이 없다(단추·찾기·필터·고르기는 흐림).
4. 개요가 칸보다 길면 세로로 스크롤.
5. 테마·언어를 바꾸면 계기·탭 이름·내용 글자가 바로 바뀐다.

## 5. 화면 글자(원문 → 영어)
- 탭(문맥 `RightTab`): 계기 → Instrument, 개요 → Overview, 상세 → Details, 메시지 → Messages, 로그 → Logs, 점검 → Checklist.
- 계기: "기체 없음" → No vehicle, "---°" 그대로.
- 개요: "기체 없음" → No vehicle, "하단 왼쪽 \"기체 연결\"에서 연결해요." → Connect from "Vehicle connection" at the bottom left., 묶음 이름 상태 → Status, 배터리 → Battery, 위치 · GPS → Position · GPS, 링크 → Link, 비행 → Flight; 줄 이름 시동 · 모드 → Arming · Mode, 잔량 → Remaining, 전압 · 전류 → Voltage · Current, 고도(상대 / AMSL) → Altitude (rel / AMSL), 속도(수평 / 수직) → Speed (horiz / vert), 홈까지 거리 → Distance to home, 연결 → Connection, 없음 → None, 비행 시간 · 거리 → Flight time · Distance.
- 상세: "값 이름 찾기" → Find a value, "기체가 연결되면 받은 값이 묶음별로 떠요." → Values appear by group once a vehicle connects.
- 메시지: 전체 → All, 오류 → Error, 경고 → Warning, 정보 → Info, "찾기" → Find, "아직 메시지가 없어요" → No messages yet, "기체가 보내는 상태 메시지가 여기에 쌓여요." → Status messages from the vehicle collect here.
- 로그: "텔레메트리 기록(tlog)" → Telemetry log (tlog), 상태 → Status, "기록 안 함(기체 없음)" → Not recording (no vehicle), 폴더 열기 → Open folder, 온보드 로그 → Onboard logs, 목록 읽기 → Read list, "기체가 연결되면 목록을 읽어요" → The list is read once a vehicle connects, 내려받기 → Download, 모두 지우기 → Erase all.
- 점검: 점검표 → Checklist, "점검표는 기체 종류에 맞춰 골라져요. 기체가 연결되면 떠요." → The checklist is chosen for the vehicle type and appears once a vehicle connects.
- 오류: "우 사이드바 계기 자리는 하나만 쓸 수 있어요." → Only one item can use the right sidebar instrument area.
