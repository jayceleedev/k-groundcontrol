### 3.2 우 탭 슬롯 — `RightTabSlot` 등록
- `Result<void> registerTab(const QString& id, int order, const QString& titleKey, const QUrl& component, RightTabPlacement placement)` — `SlotModel::add`를 쓴다(order 정렬, 같은 id면 `UiError::DuplicateId`).
- `enum class RightTabPlacement { Top, Tab }`(`Slots.h`). `Top`은 탭 줄 위 계기 칸(높이 `Theme.instrumentHeight`)에 들어가는 항목이고 **하나만** 둘 수 있다: 이미 `Top`이 있는데 또 오면 `UiError::DuplicateId`가 아니라 새 오류 `UiError::TopTaken`(`Errors.h`, `errorText` 원문 "우 사이드바 계기 자리는 하나만 쓸 수 있어요."). `Tab`은 탭 줄의 탭 하나.
- 부르는 쪽(`register.cpp`)은 결과를 `Q_ASSERT(result.has_value())`로 받는다(고정 id·자리가 겹치는 것은 프로그램 버그, `Composition`의 자리 표시 등록과 같음). `TopTaken`의 `errorText`는 기존 `DuplicateId`와 같은 번역 문맥 "Ui".
- 검사 순서: 같은 id면 `DuplicateId`가 먼저, 그다음 `Top` 중복이면 `TopTaken`. 실패한 항목은 목록에 들어가지 않는다.
- 역할: `id`·`order`(공통) + `titleKey`(번역 문맥 **"RightTab"**의 한국어 원문, 등록하는 쪽은 `QT_TRANSLATE_NOOP("RightTab", "…")`)·`component`(QML URL)·`placement`(문자열 `"top"`|`"tab"`).
- 기여(BASE §9.8 순서):

| id | 모듈 | placement | order | 이름 원문 → 영어 |
|---|---|---|---|---|
| `instrument` | vehicleInfo | Top | 0 | 계기 → Instrument(탭 줄에는 안 보임) |
| `overview` | vehicleInfo | Tab | 10 | 개요 → Status |
| `detail` | vehicleInfo | Tab | 20 | 상세 → Data |
| `messages` | vehicleInfo | Tab | 30 | 메시지 → Msgs |
| `logs` | logs | Tab | 40 | 로그 → Logs |
| `preflight` | preflight | Tab | 50 | 점검 → Check |

### 3.3 계기 부품 — `AttitudeIndicator`(`platform/ui` components)
- 공용 부품으로 둔다(세컨드 패널 칸에서 다시 쓸 것을 염두 — 사용자 결정 §10-4). 속성 `roll`·`pitch`(도), `heading`(도, 0~360), `available`(bool, 기본 거짓).
- `available`이 참이면: 원(반지름 `r`) 안에 하늘·땅 두 색과 수평선을 그린다. 항공 자세계 관례를 따른다: **`roll` +(오른쪽으로 기울임)이면 수평선이 화면에서 반시계 방향으로 `roll`도 돈다**, **`pitch` +(기수 들기)이면 수평선이 아래로 `pitch × r / 30` 픽셀 옮겨진다**(±30°에서 원 가장자리; 그 너머도 같은 식으로 그리고 원 밖은 잘림; 값은 −90~90으로 제한). 눈금: pitch ±10°·±20°(수평선과 함께 움직임), roll 0·±30·±60(원 위쪽 가장자리, 고정). 수평선과 함께 도는 roll 지침(작은 삼각형) 하나가 위쪽 눈금을 가리킨다. 가운데 고정 기체 표시. 아래에 헤딩 `"%1°"`: 입력 `h`를 `((h mod 360) + 360) mod 360`으로 맞춘 뒤 반올림(360이 되면 0), 0 채움 없음; 숫자가 아니면(NaN) "---°".
- 시험이 재는 고정 이름: 수평선·하늘·땅을 함께 돌리고 옮기는 안쪽 항목 objectName **`attitudeHorizon`**(`rotation == -roll`, 가운데에서 아래로 옮긴 거리 = `pitch × dialRadius / 30`), 읽기 전용 속성 **`dialRadius`**(원 반지름 픽셀), 헤딩 글자 objectName **`attitudeHeading`**, 하늘·땅을 칠하는 두 항목 objectName **`attitudeSkyFill`**·**`attitudeGroundFill`**(`color`를 읽음; 색 토큰 `attitudeSky`·`attitudeGround`와 다른 이름). 옮김은 도는 항목 안쪽 좌표의 y축(수평선에 수직 방향)으로 한다.
- `available`이 거짓이면: 수평선을 0°로, 하늘·땅을 둘 다 `surfaceAlt` 한 색으로 흐리게 그리고, 가운데 아래 글자 **"기체 없음"**(`inkMuted`), 헤딩 자리는 **"---°"**.
- 색 토큰 **`attitudeSky`·`attitudeGround`**를 `ThemeBase.qml`(required)과 네 테마 파일에 더한다(검사 `theme_tokens`). 값: Light·AeroLight `#dbeafe`·`#d6d3d1`, Dark·AeroDark `#1e3a5f`·`#44403c`. 크기 토큰은 `Theme.qml`에 이름으로(0.0.2 §3.5 규칙). 그림은 Shape `CurveRenderer`(0.0.2 T26과 같은 선명도 규칙).
- UI 부품 목록(uiGallery)의 **차트** 부문(`GalleryCharts.qml`)에 견본: `available` 토글과 roll·pitch·heading 슬라이더.

### 3.4 빈 상태 부품 — `EmptyState`(`platform/ui` components)
- 상자 가운데에 제목 한 줄과 설명(둘 다 `inkMuted`, 제목은 `fontSize`, 설명은 새 토큰 `Theme.captionSize`(= `Math.round(11 * uiScale)`), 설명은 폭에 맞춰 줄바꿈), 테두리 점선 `line`. 속성 `title`·`detail`(비면 설명 줄 없음). 높이: 기본은 내용 높이 + 위아래 `Theme.inset`, 부르는 쪽이 `Layout.fillHeight`로 남은 칸을 채우게 할 수 있다. 개요에서는 내용 높이, 상세·메시지·로그·점검에서는 남은 칸을 채운다(와이어프레임). 누를 것 없음. uiGallery의 **알림** 부문(`GalleryNotices.qml`)에 견본.

### 3.5 셸 — `RightBar.qml`
- 맨 위 계기 칸 `rightTop`(높이 `Theme.instrumentHeight`, 바깥 여백 `Theme.inset`): `placement=="top"` 항목의 `component`를 `Loader`로 싣는다. 없으면 지금처럼 빈 상자.
- 그 아래 탭 줄 `rightTabs`(높이 `Theme.rightTabHeight`): `TabStrip`, `placement=="tab"` 항목을 order 순서로 **줄 폭을 탭 수로 똑같이 나눠** 채우고(단추 높이 = 줄 높이, 단추 가로 안쪽 여백 `Theme.inset / 2`), 이름이 칸보다 길면 끝을 `…`로 줄인다(줄바꿈·가로 스크롤 없음; 줄인 탭은 마우스를 올리면 전체 이름 힌트). 이름은 `qsTranslate("RightTab", titleKey)`(`Translator.language`에 다시 묶음). 탭 단추 objectName **`rightTab_<id>`**(`Top` 항목은 탭 줄 모델에 넣지 않아 단추 객체가 없다). 처음 고른 탭 = order가 가장 작은 탭(개요). 고른 탭은 기억하지 않는다(다음 실행엔 다시 개요).
- 그 아래 내용 칸 `rightTabContent`: 고른 탭의 `component`를 `Loader`로 싣는다. 실린 항목의 높이 = max(자기 내용 높이, 칸 높이). 내용이 칸보다 길 때만 **세로로 스크롤**하고 세로 스크롤바가 보인다(가로 스크롤 없음). 스크롤바는 내용 위 오른쪽 `Theme.inset` 여백 안에 겹쳐 그려 내용 폭을 줄이지 않는다. 탭을 바꾸면 새 탭이 맨 위에서 시작.
- shell은 `RightTabPlacement`·탭 id를 모른 채 역할 값만 읽는다(잎 모듈).
