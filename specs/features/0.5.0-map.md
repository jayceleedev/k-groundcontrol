## 2. 사용자 결정 (2026-11-26, `.pm/0.5.0/decisions.md`)
1. 범위: 기본 지도 + 영역 미리 받기.
2. 지도는 바닥이 아니라 **지도 부품**이다. 0.5.0은 가운데 영역(바 안쪽)에 하나 놓는다. 타일 받기·저장·지도 종류는 전역 하나를 모든 부품이 같이 쓰고, 위치·확대는 부품마다 따로다. 배경 설정(민무늬·체크무늬·사진)은 그대로 UI를 뺀 맨 바닥이다. 유리 테마에서 바 밑에는 배경이 비친다. 패널은 가운데 지도 위에 뜬다.
3. 제공자는 Mission Planner처럼: Google 지도 타일 주소를 직접 쓰고, 모든 지도 종류에서 영역 받기를 켠다(제공자 조사 `.pm/research/map-providers.md`를 본 뒤 고름).
4. 지도 종류는 Google **위성·하이브리드·일반** 셋. 기본은 위성. 키 입력 화면은 없다.
5. (2026-11-27) 본 타일 저장 한도, 궤적 점 간격·최대 점 수, 따라가기 자동 켜기는 코드 고정값이 아니라 **운영 설정**이다. 바꾸는 곳은 앱 설정 패널의 새 "지도" 칸(일반·화면·조작 다음, 정보 앞, §5.9).

PM이 정한 것(승인 때 함께 확인):
- 그리기: Qt Location `Map` 위에 **우리 정적 geoservice 플러그인**(provider `kgc`)을 붙이고, 타일은 그 플러그인이 `Http`로 받는다. 플러그인은 `kgc_map` 안에 함께 컴파일한다. Qt Location은 Qt 6.12에서도 Technology Preview다(`.pm/research/map-engine.md`). Qt Location 비공개 API(`*_p.h`, `Qt6::LocationPrivate`)는 `features/map/internal/geoservice/`에서만 쓰고, Qt를 올릴 때마다 지도를 다시 확인한다. 그래서 Linux 빌드에 `libxkbcommon-dev`가 새로 필요하다(CI와 개발 PC 모두).
- 처음 켤 때 위치: 위도 36.5, 경도 127.8, 확대 7(한국 전체). 그 뒤로는 가운데 지도를 마지막으로 본 곳. 다른 지도 부품도 그곳에서 시작한다(저장은 가운데 지도만).
- 기체 아이콘은 기체 종류와 상관없이 화살표 하나이고, 기수 방향으로 돌아간다. 지도 색은 네 테마에서 같다.
- 위도·경도가 둘 다 0인 위치는 지도에서 "위치 없음"으로 본다(ArduPilot이 위치를 얻기 전에 보내는 값). 아이콘·따라가기·궤적·홈 모두 같고, 기체 상태 값은 바꾸지 않는다.
- 따라가기: 설정 "따라가기 자동 켜기"(기본 켬)가 켜져 있으면 활성 기체가 위치를 가질 때 켜지고, 활성 기체가 바뀌면(사용자가 꺼 두었어도) 다시 켜진다. 그 설정이 꺼져 있으면 저절로 켜지지 않고(활성 기체가 바뀌면 꺼진다) 단추로만 켠다. 설정을 바꾸는 것만으로 지금의 따라가기가 켜지거나 꺼지지는 않는다. 지도를 끌거나 영역 고르기에 들어가면 꺼지고, 단추로 다시 켠다. 켜져 있는 동안 휠·핀치·확대 단추는 지도 가운데(기체)를 기준으로 확대하고 따라가기는 그대로다.
- 궤적: 기체마다 마지막으로 더한 점에서 "궤적 점 간격"(설정, 기본 1 m, 0.1~100 m)보다 많이 움직였을 때만 점을 더하고, 기체마다 "궤적 최대 점 수"(설정, 기본 20,000, 1,000~200,000)까지 둔다(넘으면 가장 오래된 점부터 버림). 간격을 바꾸면 다음 점부터 적용하고, 최대 점 수를 줄이면 넘는 점을 바로 오래된 쪽부터 버린다. 지우기 단추는 모든 기체의 궤적을 지운다.
- 저장: 본 타일은 합 "본 타일 저장 한도"(설정, 기본 2048 MB = 2 GiB, 256~102,400 MB)까지 둔다(넘으면 가장 오래 안 본 것부터 지움; 한도를 줄이면 바로 지운다). 영역 받기로 받은 타일은 비우기 전까지 지우지 않는다. 저장 크기 보기와 비우기는 지도의 "지도 저장" 카드에 둔다(저장 한도는 앱 설정의 "지도" 칸). 저장소 파일이 깨져 열리지 않으면 한 번 지우고 새로 만든다(미리 받은 타일도 사라진다). 그래도 안 되면 저장 없이 온라인으로만 보이고, 그동안 영역 받기는 시작하지 않는다(받아도 남지 않으므로).
- 영역 받기: 지도에서 끌어서 사각형을 고르고 확대 범위를 정한다. 기본 범위는 고른 순간 확대의 내림 ~ 그 +4(최대 20). 한 번에 100,000개까지, 한 번에 하나만. 지금 보이는 지도 종류(라벨 있는 종류는 지금 언어)로 받는다. 받는 동안 카드는 공용 `JobView` 그대로(단계·진행선·남은 시간·취소)이고 받은 개수는 보이지 않는다.
- 지명 언어는 앱 언어(한국어 `ko`, 영어 `en`)를 따른다. 위성은 라벨이 없어 언어와 무관하다. 언어를 바꾸면 보이는 타일이 비었다가 다시 채워진다(하이브리드·일반은 서버에서, 위성은 저장소에서).
- 확대 범위 2~20(창이 넓으면 가장 작은 확대는 지도가 창을 채우는 값, 지도 폭 1900 px이면 약 2.9), 타일 256 px.
- 타일 요청 머리글은 앱 기본값(User-Agent `K-GroundControl/<버전>`)이고 Referer·브라우저 흉내는 넣지 않는다. U1에서 Google이 거절하면(앱 로그 "Request failed: …, HTTP 403") 사용자에게 다시 묻는다.
- 시험용 부팅 설정(명령줄 전용, 사용자에게 보이지 않음): `--tile-host <https 주소>`는 Google 주소 대신 시험 서버를 쓰게 하고, `--tile-ca <PEM 파일>`은 그 서버 인증서를 믿게 한다(HTTPS만 규칙 유지, `.pm/0.5.0/decisions.md` 6).

### 5.2 새 바탕 모듈 `app/store` (`kgc_app_store`, 층 0, `ModuleId` 21, 이름공간 `kgc::app::store`)
QtSql은 여기서만 쓴다(BASE §9.3). 기능을 모르는 범용 덩이 저장소 `BlobStore` 하나(pimpl, 헤더에 QSql 형 없음). `CMakeLists.txt`: `add_library(kgc_app_store STATIC …)`, `target_link_libraries(kgc_app_store PUBLIC kgc_app_errors Qt6::Core PRIVATE kgc_app_log Qt6::Sql)`.
```cpp
class BlobStore {   // 만든 스레드에서만 써요(Qt는 다른 스레드에서 써도 경고하지 않아요)
public:
    static kgc::app::errors::Result<std::unique_ptr<BlobStore>> open(const QString& path, const QString& connectionName);
    ~BlobStore();
    kgc::app::errors::Result<std::optional<QByteArray>> get(const QString& key);   // 있으면 used를 지금(ms)으로
    kgc::app::errors::Result<void> put(const QString& key, const QByteArray& data, bool pinned);
    kgc::app::errors::Result<bool> pin(const QString& key);                        // 없으면 false
    kgc::app::errors::Result<qint64> totalBytes();
    kgc::app::errors::Result<qint64> pinnedBytes();
    kgc::app::errors::Result<void> evictUnpinned(qint64 limitBytes);
    kgc::app::errors::Result<void> clear();
private:
    struct Private;
    std::unique_ptr<Private> d_;
};
```
- `open`: `QSqlDatabase::addDatabase("QSQLITE", connectionName)` → `open()` → `PRAGMA journal_mode=WAL`(돌려받은 값을 로그) → `PRAGMA synchronous=NORMAL` → `CREATE TABLE IF NOT EXISTS blobs(key TEXT PRIMARY KEY, data BLOB NOT NULL, bytes INTEGER NOT NULL, pinned INTEGER NOT NULL, used INTEGER NOT NULL)` → `CREATE INDEX IF NOT EXISTS blobs_evict ON blobs(pinned, used)`. 어느 단계든 실패하면(깨진 파일은 `open()`이 되고 첫 PRAGMA에서 실패한다) `db.close(); db = QSqlDatabase(); QSqlDatabase::removeDatabase(connectionName);` 뒤 `OpenFailed`.
- 소멸자: `close()`, 마지막 손잡이를 `QSqlDatabase()`로 비운 뒤 `removeDatabase`.
- `put`: `INSERT … ON CONFLICT(key) DO UPDATE SET data=excluded.data, bytes=excluded.bytes, used=excluded.used, pinned=(blobs.pinned OR excluded.pinned)`. `bytes` = `data.size()`, `used` = 지금(ms). 한 번 고정되면 `put`으로 풀리지 않는다.
- `evictUnpinned(limit)`: `SELECT SUM(bytes) FROM blobs WHERE pinned=0`이 `limit` 이하면 아무것도 하지 않는다. 넘으면 `DELETE FROM blobs WHERE key IN (SELECT key FROM (SELECT key, SUM(bytes) OVER (ORDER BY used DESC, key ROWS UNBOUNDED PRECEDING) AS kept FROM blobs WHERE pinned=0) WHERE kept > ?)`(최근에 본 것부터 한도까지 남김).
- `clear`: `DELETE FROM blobs` 뒤 트랜잭션 밖에서 `VACUUM`.
- 오류 `enum class StoreError : std::uint16_t { OpenFailed = 1, QueryFailed }`, `make`, `errorText`(문맥 "Store", §6). 로그 범주 `kgc.app.store`, `enum class StoreEvent : std::uint16_t { Opened = 1, OpenFailed, QueryFailed }`(문구 §6).
- `MODULE.md` 새로. 시험은 §8 T10.

### 5.4 `app/boot`·`app/net`·`main` — 시험 서버와 HTTP 상태
**`app/boot`**
- `BootOptions`에 `QString tileHost; QString tileCa;`(기본 빈 값). 명령줄에서만 읽고 `kgc.ini`에는 두지 않는다. 옵션 `{"tile-host", QT_TRANSLATE_NOOP("BootOptions", "타일 서버 주소(시험용)"), "url"}`, `{"tile-ca", QT_TRANSLATE_NOOP("BootOptions", "타일 서버 인증서 PEM 파일(시험용, 이번 실행의 모든 HTTPS 요청이 믿음)"), "file"}`.
- 순수 함수 `static std::optional<QString> BootOptions::parseTileHost(const QString& value)`: `QUrl(value, QUrl::StrictMode)`가 유효하고, scheme이 `https`, host가 있고, 경로가 비었거나 `/`, 질의·조각·사용자 정보가 없으면 `url.adjusted(QUrl::RemovePath).toString()`(끝 `/` 없음, 호스트 소문자), 아니면 값 없음. `parse`는 `--tile-host`가 있으면 이것을 부르고, 값 없음이면 `QCommandLineParser::showMessageAndExit(Error, QString(QT_TRANSLATE_NOOP("BootOptions", "타일 주소는 https://호스트[:포트] 꼴이어야 함: %1")).arg(value), 1)`.
- `[[noreturn]] static void exitBadCertificate(const QString& path)`: `showMessageAndExit(Error, QString(QT_TRANSLATE_NOOP("BootOptions", "시험용 인증서를 읽을 수 없음: %1")).arg(path), 1)`. 문구는 `BootOptions.cpp`에 둔다(`kgc_app_boot`가 lupdate 대상).
- `MODULE.md`의 받는 것·주는 것·안 하는 것을 새 옵션 둘에 맞춰 고친다.

**`app/net`** (api 변경)
- `HttpError`에 `BadCertificate = 8, HttpStatus = 9`(문구 §6). `NetEvent`에 `CertificateTrusted = 3`. `internal/Constants.h`에 `inline constexpr int kHttpErrorStatusMin = 400;`.
- `Http.h`에 `kgc::app::errors::Result<void> trustCertificateFile(const QString& pemPath)`: `auto config = QSslConfiguration::defaultConfiguration(); if (!config.addCaCertificates(pemPath, QSsl::Pem)) return std::unexpected(make(HttpError::BadCertificate)); QSslConfiguration::setDefaultConfiguration(config);` 뒤 WARN `NetEvent::CertificateTrusted` "Extra CA trusted: <path>". 꼭 **경로를 받는** `addCaCertificates`를 쓴다(목록을 받는 것은 시스템 루트 인증서를 필요할 때 읽는 기능을 끈다 — 이 까닭을 주석으로). 시스템 루트 인증서도 계속 믿는다. 첫 HTTPS 요청 전에 한 번만 부르고, 그 실행의 모든 HTTPS 요청(펌웨어·SITL 받기 포함)이 그 인증서를 믿는다.
- `Http.h`(`<QNetworkReply>`·`<QVariant>` include)에 순수 함수 `HttpError failureOf(QNetworkReply::NetworkError error, const QVariant& httpStatus)`: `httpStatus`가 유효한 수이고 `kHttpErrorStatusMin` 이상이면 `HttpStatus`, 아니고 `error == QNetworkReply::TimeoutError`면 `TimedOut`, 그 밖은 `NetworkFailed`(200 머리글 뒤 본문 중에 끊긴 것은 상태 오류가 아니다).
- `Http.cpp`의 `received()`: 재시도 고리는 그대로다(HTTP 상태 오류도 지금처럼 `retries`만큼 다시 보낸다). 마지막 실패의 오류만 `failureOf(reply->error(), reply->attribute(QNetworkRequest::HttpStatusCodeAttribute))`(떼어 내기 전에 읽음)로 정하고, 그때 WARN `NetEvent::RequestFailed`: `HttpStatus`면 "Request failed: <host>, HTTP <status>", 아니면 "Request failed: <host>, TimedOut" 또는 "…, NetworkFailed"(같은 문구 반복 허용). `<kgc/app/log/Log.h>`·`"Events.h"`·`"Constants.h"`를 include.
- `onlineChanged`: 결과가 `Aborted`면 상태를 바꾸지 않는다. 성공이나 `HttpStatus`면 온라인, 그 밖의 실패는 오프라인(지금과 같음).
- `features/sitl/internal/SitlDownload.cpp`의 `downloadErrorName` switch에 `case HttpError::BadCertificate: return QStringLiteral("BadCertificate");`와 `HttpStatus` 줄.
- `MODULE.md`: 주는 것에 `trustCertificateFile`·`failureOf`, "시험용 인증서는 그 실행의 모든 HTTPS 요청에 적용". 시험은 §8 T9.

**`main.cpp`**: `LogSink::attachFeed` 바로 뒤, `Settings::instance` 앞에 `if (!boot.tileCa.isEmpty() && !kgc::app::net::trustCertificateFile(boot.tileCa)) kgc::app::boot::BootOptions::exitBadCertificate(boot.tileCa);`. docstring 흐름에 5단계 "trustCertificateFile — --tile-ca가 있으면 시험 서버 인증서를 믿어요(첫 HTTPS 요청 전)."를 넣고 뒤 번호를 하나씩 민다. Composition은 `new kgc::Composition(engine, {...}, translator, feed, boot)`(§5.8). 테스터는 `KGroundControl --tile-host https://127.0.0.1:<port> --tile-ca ca.pem`으로 켠다.

#### 5.6.3 internal 순수 함수 (저장소 테스트 대상)
- `TileUrl`: `QString tileUrl(settings::MapType type, const QString& language, int z, int x, int y, const QString& host)` — 앞부분은 `host`가 비면 `https://mt{n}.google.com`(n = (x + y) mod 4), 아니면 `host`(`parseTileHost`를 거친 값) 그대로. 뒤는 `/vt/lyrs={s|y|m}&hl={language}&x={x}&y={y}&z={z}`(위성도 `hl`을 붙인다). `QString tileKey(settings::MapType type, const QString& language, int z, int x, int y)` — 위성 `s/{z}/{x}/{y}`, 하이브리드 `y/{language}/{z}/{x}/{y}`, 일반 `m/{language}/{z}/{x}/{y}`.
- `TileMath`: `struct TileXY { int x; int y; };`, `struct TileRange { int x; int y; int columns; int rows; };`
  - `TileXY tileOf(double lat, double lon, int z)` — 웹 메르카토르. 위도는 ±`kMaxMercatorLatitude`로 자르고 x = ⌊(lon + 180)/360 · 2^z⌋, y = ⌊(1 − ln(tan φ + sec φ)/π)/2 · 2^z⌋, 둘 다 0 ~ 2^z − 1로 자른다.
  - `TileRange tileRange(const QGeoRectangle& area, int z)` — (x, y) = `tileOf(area.topLeft())`, (x2, y2) = `tileOf(area.bottomRight())`. `rows = y2 − y + 1`. 날짜 변경선을 넘지 않으면(`area.topLeft().longitude() <= area.bottomRight().longitude()`) `columns = x2 − x + 1`, 넘으면 `columns = min(2^z, x2 − x + 2^z + 1)`. 열 i(0부터)의 타일 x는 `(x + i) mod 2^z`.
  - `qint64 tileCount(const QGeoRectangle& area, int minZoom, int maxZoom)` — 각 확대의 `columns × rows` 합.
  - `double metersPerPixel(double lat, double zoom)` = `kMetersPerPixelAtZoom0` · cos(lat) / 2^zoom.
- `ScaleBar`: `struct ScaleBarLength { double meters; int pixels; };`. `ScaleBarLength scaleBar(double metersPerPixel, int maxPixels)` — {1, 2, 5} × 10^k m(k ≥ 0) 가운데 `maxPixels` 안에 드는 가장 긴 것, `pixels`는 반올림. `QString scaleLabel(double meters)` — 1000 미만은 "N m", 이상은 "N km"(정수가 아니면 소수 한 자리, "1.5 km"). 단위 글자는 번역하지 않는다.
- `SizeText`: `QString sizeText(qint64 bytes)` — `kBytesPerKilobyte`(1024) 단위. 1024² 미만 KB, 1024³ 미만 MB, 그 밖 GB(단위는 반올림 전에 고른다). 수는 `QString::number(static_cast<double>(bytes) / static_cast<double>(unit), 'f', 1)`에서 끝의 ".0"을 뺀다. 글은 "%1 %2"(단위 번역 안 함, 자릿수 구분 없음).
- `TileImage`: `QString tileImageFormat(const QByteArray& bytes)` — `FF D8 FF`로 시작하면 "jpeg", `89 50 4E 47 0D 0A 1A 0A`로 시작하면 "png", 그 밖은 빈 문자열. 바이트는 문자열 리터럴로 비교한다(6자리 넘는 16진 정수는 고정값 검사에 걸린다).
- `Trail`: `bool isMapPosition(double latDeg, double lonDeg)` — 둘 다 유한하고 둘 다 0은 아니면 참. `bool appendTrailPoint(QList<QGeoCoordinate>& points, const QGeoCoordinate& next, double minMeters, int maxPoints)` — `isMapPosition(next.latitude(), next.longitude())`가 거짓이면 거짓. 마지막 점과의 `distanceTo`가 `minMeters` 이하면 거짓. 아니면 더하고, 개수가 `maxPoints`를 넘으면 넘는 만큼 앞에서 지운 뒤 참.
- `DownloadPlan`: `kgc::app::errors::Result<qint64> planDownload(const QGeoRectangle& area, int minZoom, int maxZoom)` — `kMinZoom ≤ minZoom ≤ maxZoom ≤ kMaxZoom`이 아니면 `BadZoomRange`, `tileCount`가 `kMaxDownloadTiles`를 넘으면 `TooManyTiles`, 아니면 개수.

#### 5.6.5 타일 저장소 `TileStore` (워커 스레드)
- `class TileStore : public QObject` — 부모 없음, 생성자는 일하지 않는다. 함수(모두 워커에서 불림): `open(const QString& path, qint64 limitBytes)`, `setLimit(qint64 limitBytes)`, `lookup(quint64 requestId, const QString& key)`, `save(const QString& key, const QByteArray& bytes, bool pinned)`, `pin(quint64 requestId, const QString& key)`, `size()`, `clear()`. 신호: `found(quint64 requestId, QByteArray bytes)`, `missing(quint64 requestId)`, `pinned(quint64 requestId, bool pinned)`, `sized(qint64 totalBytes, qint64 pinnedBytes)`, `cleared()`, `failed(kgc::app::errors::ErrorCode error)`.
- `open`: `BlobStore::open(path, "mapTiles")`. 실패하면 `path`, `path + "-wal"`, `path + "-shm"`을 `QFile::remove`로 지우고(폴더는 지우지 않는다) WARN `StoreReset` "Map store reset: <path>" 뒤 한 번 더 연다. 또 실패하면 WARN `StoreFailed` "Map store failed: " + `tileErrorName(두 번째 BlobStore::open의 오류)`(보통 "21:1")와 `failed(make(MapError::StoreFailed))`, 그 뒤로는 저장 없이 답한다: `lookup` → `missing`, `pin` → `pinned(id, false)`, `save`는 버림, `size`·`clear` → `failed(make(MapError::StoreFailed))`. 열리면 `evictUnpinned(limitBytes)` 한 번, 그 뒤 `save` `kEvictEverySaves`번마다 그때의 한도로 한 번. `setLimit`은 한도를 바꾸고 바로 `evictUnpinned`를 한 번 한다(저장 없이 답하는 동안은 한도만 바꾼다).
- 실행 중 `BlobStore` 호출이 실패하면 그 호출은 위의 저장 없는 답을 하고 `failed(make(MapError::StoreFailed))`를 낸다. `lookup`은 `get`(있으면 `used` 갱신)으로 `found`/`missing`, `pin`은 `BlobStore::pin`으로 `pinned`, `size`는 `totalBytes`·`pinnedBytes`로 `sized`.
- 스레드(`MapService::Private`가 `QThread storeThread`와 `TileStore* store`를 가짐, FcFlashService 선례): `store->moveToThread(&storeThread)`; `connect(&storeThread, &QThread::started, store, [store, path, limit] { store->open(path, limit); })`(path = `Paths::cacheTiles() + "/tiles.sqlite"`, limit = `qint64(settings::tileStoreLimitMb()) * kBytesPerKilobyte * kBytesPerKilobyte`); `settings::onTileStoreLimitMbChanged(this, …)` → 같은 식으로 바이트를 셈해 `QMetaObject::invokeMethod(store, [store, bytes] { store->setLimit(bytes); })`; `finished` → `deleteLater`; TileStore의 신호를 모두 이은 **뒤** `start()`(열기 실패 신호를 놓치지 않게). GUI → 저장소는 `QMetaObject::invokeMethod(store, [=] { store->lookup(id, key); })`(큐), 저장소 → GUI는 신호(스레드가 달라 큐). `~MapService`: `QObject::disconnect(store, nullptr, nullptr, nullptr)`, `storeThread.quit()`, `storeThread.wait()`(지우기가 워커 안에서 끝나 DB가 제 스레드에서 닫힘).

#### 5.6.6 타일 공급 `TileSource` (GUI 스레드)
```cpp
using TileTicket = quint64;   // 0은 "없음"
class TileSource : public QObject {
    Q_OBJECT
public:
    TileSource(kgc::app::net::Http& http, TileStore& store, QString host, QObject* parent);
    QString language() const;
    void setLanguage(const QString& language);   // 같은 값이면 아무것도 안 함, 다르면 languageChanged
    TileTicket fetch(settings::MapType type, const QString& language, int z, int x, int y, bool pin,
                     std::function<void(kgc::app::errors::Result<QByteArray>)> done);
    void cancel(TileTicket ticket);
signals:
    void languageChanged();
    void onlineAgain();
};
QString tileErrorName(kgc::app::errors::ErrorCode error);   // "<모듈 번호>:<오류 번호>", 로그와 Qt 오류 글자(영어만)
```
- 대기표 `QHash<QString, Pending>`(키 = `tileKey`). 저장소 `requestId`는 1부터 늘리고, 0은 답을 버리는 호출에 쓴다. `Pending`은 단계(`Pin`·`Lookup`·`Http`), 저장소 `requestId`, `QPointer<HttpRequest> request`, `retries`, 기다리는 사람 목록 `QList<Waiter>`(`struct Waiter { TileTicket ticket; bool pin; std::function<…> done; }`)을 든다.
- `fetch`: 같은 키가 대기 중이면 `Waiter`만 더한다(새 요청 없음). 아니면 새 대기 — `pin`이 참이면 `Pin` 단계(`TileStore::pin`), 거짓이면 `Lookup` 단계(`TileStore::lookup`). `retries`는 대기를 만든 사람이 정한다: `pin ? 1 : 0`(지도 요청은 Qt가 다시 요청하므로 0). 나중에 낀 사람은 그대로 따른다.
- `pinned(id, true)`: `pin`인 사람에게 빈 바이트로 성공. `pin` 아닌 사람이 남았으면 그들을 위해 `Lookup`으로, 없으면 대기를 지운다. `pinned(id, false)`: `Http` 단계로.
- `found(id, bytes)`: 모두에게 `bytes`. 기다리는 사람 중 `pin`이 있으면 `TileStore::pin(0, key)`도 부른다(답은 버림). `missing(id)`: `Http` 단계로.
- `Http` 단계: `http.get(tileUrl(type, language, z, x, y, host_), {kTileTimeout, retries, {}})`(머리글은 Http 기본값만). 끝나면 — 성공이고 `tileImageFormat`이 비지 않으면 `TileStore::save(key, bytes, 기다리는 사람 중 하나라도 pin)` 뒤 모두에게 `bytes`; 성공인데 그림이 아니면 저장하지 않고 모두에게 `make(MapError::TileFailed)`; 실패면 모두에게 그 오류.
- 답은 그 대기의 `requestId`나 `request` 포인터가 맞을 때만 쓴다. 그 밖(이미 지운 대기, `Aborted`)은 버린다.
- `cancel(ticket)`: 그 `Waiter`를 뺀다. 남은 사람이 없으면 대기를 **먼저 지우고**, `Http` 단계였으면 `request->abort()`. 다른 지도나 받기 작업이 기다리는 요청은 살아 있다.
- 콜백은 언제나 나중에(큐로) 불린다. `fetch`가 돌려준 표가 콜백보다 먼저 손에 들어온다.
- 실패 로그: 키마다 한 번(이번 실행) WARN `TileFailed` "Tile failed: <key>, <tileErrorName>".
- 온라인(TileSource 자신의 판정, `Http::onlineChanged`는 쓰지 않음): 닿음 = 성공·`HttpStatus`·`TileFailed`, 안 닿음 = `NetworkFailed`·`TimedOut`, `Aborted`는 무시. 안 닿음 → 닿음으로 바뀔 때 `onlineAgain()`. 안 닿는 동안 이름 붙은 `Timeout` "mapOnlineProbe"가 `kOnlineProbeInterval`마다 마지막으로 실패한 타일 주소를 `retries 0`으로 한 번 보낸다(본문은 저장하지 않음). 닿으면 멈춘다. Qt가 다시 요청을 포기한 뒤에는 이것 말고 요청이 없어서 필요하다.

#### 5.6.7 Qt Location 플러그인 `internal/geoservice/` (Qt 비공개 헤더는 이 폴더에서만)
- `kgc_plugin.json`(헤더 옆): `{"Keys": ["kgc"], "Provider": "kgc", "Version": 100, "Experimental": false, "Features": ["OnlineMappingFeature"]}`. Version은 정수, Experimental은 bool이어야 Qt가 읽는다.
- `class KgcGeoServiceFactory : public QObject, public QGeoServiceProviderFactory` — `Q_OBJECT`, `Q_INTERFACES(QGeoServiceProviderFactory)`, `Q_PLUGIN_METADATA(IID "org.qt-project.qt.geoservice.serviceproviderfactory/6.0" FILE "kgc_plugin.json")`. `setQmlEngine(QQmlEngine*)` 재정의는 `QPointer`로 든다(Qt가 엔진을 만들기 전에 부름). `createMappingManagerEngine(params, error, errorString)`: `qobject_cast<TileSource*>(engine_->property(kTileSourceProperty).value<QObject*>())`가 없으면 `*error = QGeoServiceProvider::NotSupportedError`, `*errorString = "kgc: no tile source"`, `nullptr`. 있으면 `new KgcMappingEngine(*source, error, errorString)`(엔진이 `*error = QGeoServiceProvider::NoError`, `errorString->clear()`). 비공개 헤더는 `<QtLocation/private/…_p.h>` 꼴로 include한다.
- `KgcMappingEngine : QGeoTiledMappingManagerEngine`, 생성자 `KgcMappingEngine(TileSource& source, QGeoServiceProvider::Error* error, QString* errorString)`, 이 순서로:
  1. `QGeoCameraCapabilities`: `setMinimumZoomLevel(kMinZoom)`, `setMaximumZoomLevel(kMaxZoom)`, `setSupportsBearing(false)`, `setSupportsTilting(false)`, `setOverzoomEnabled(false)` → `setCameraCapabilities`; `setTileSize(QSize(kTileSize, kTileSize))`.
  2. `setSupportedMapTypes`: `settings::MapType` 순서로 셋 — id 1 `QGeoMapType::SatelliteMapDay`, 2 `HybridMap`, 3 `StreetMap`, 이름 "Satellite"·"Hybrid"·"Road"(화면에 쓰지 않음), 설명 빈 값, mobile·night 거짓, plugin 이름 "kgc", 1의 카메라 능력.
  3. `setCacheHint(QAbstractGeoTileCache::MemoryCache)`, `setTileCache(new KgcTileCache)`(fetcher보다 먼저).
  4. `setTileFetcher(new KgcTileFetcher(source, this))`.
  5. `connect(&source, &TileSource::languageChanged, this, [this] { setTileVersion(tileVersion() + 1); })` — 모든 지도가 보이는 타일을 새 판으로 다시 요청한다(하이브리드·일반은 새 `hl`로 서버에서, 위성은 서버 요청 없이 TileStore에서). 보이는 타일은 비었다가 답이 오는 대로 채워지고, 그 사이 카메라가 움직이면(따라가기) 화면 전체가 비었다가 채워진다.
  6. `connect(&source, &TileSource::onlineAgain, this, &KgcMappingEngine::refreshVisible)`.
  - `createMap()` 재정의(기본은 NULL): `auto* map = new QGeoTiledMap(this, nullptr); map->setPrefetchStyle(QGeoTiledMap::NoPrefetching); maps_.removeAll(nullptr); maps_.append(map); return map;`(`QList<QPointer<QGeoTiledMap>> maps_`).
  - `refreshVisible()`: 살아 있는 `maps_`마다 `clearScene(map->activeMapType().mapId())`. 그림도 캐시도 없는 보이는 타일만 다시 요청된다.
- `KgcTileCache : QGeoFileTileCache` — 생성자 `KgcTileCache(QObject* parent = nullptr) : QGeoFileTileCache(QString(), parent)`. `init()` 재정의는 `setMaxDiskUsage(0); setMaxMemoryUsage(kTileMemoryCacheBytes); setExtraTextureUsage(kTileExtraTextureBytes);`만 한다(기본 `init`을 부르지 않아 디스크 폴더를 만들거나 지우지 않는다). `clearAll()` 재정의는 `textureCache_.clear(); memoryCache_.clear(); diskCache_.clear();`(기본은 작업 폴더의 `*-*-*-*.*` 파일을 지운다). `clearMapId()`는 부르지 않는다(가상이 아니고 작업 폴더를 훑는다 — 헤더에 주석).
- `KgcTileFetcher : QGeoTileFetcher`(`QPointer<TileSource> source_`): `getTileImage(spec)` — 소스가 없거나 `spec.mapId()`가 1~3이 아니면 `new QGeoTiledMapReply(QGeoTiledMapReply::UnknownError, QStringLiteral("unknown map type"), this)`(이미 끝난 답), 아니면 `new KgcTileReply(spec, *source_, this)`.
- `KgcTileReply : QGeoTiledMapReply`(같은 파일): 생성자에서 `ticket_ = source.fetch(settings::MapType(spec.mapId() - 1), source.language(), spec.zoom(), spec.x(), spec.y(), false, [self = QPointer<KgcTileReply>(this)](const auto& r) { if (self) self->deliver(r); });`. `abort()` 재정의와 소멸자는 `if (source_ && ticket_) source_->cancel(ticket_); ticket_ = 0;`(abort는 이어서 `QGeoTiledMapReply::abort()`). 비공개 `deliver(const kgc::app::errors::Result<QByteArray>& result)`: `ticket_ = 0; if (isFinished()) return;` 성공이면 `setMapImageData(bytes); setMapImageFormat(tileImageFormat(bytes)); setFinished(true);`, 실패면 `setError(QGeoTiledMapReply::CommunicationError, tileErrorName(error))`. `errorText`는 쓰지 않는다(Qt가 이 글자를 앱 로그에 남긴다). 실패한 타일은 Qt가 0.5·1·2·4·8초 뒤 다시 요청하고 다섯 번 뒤 포기한다(경고 "giving up"이 `kgc.qt`로 남음).
- 공급자 넘기기(전역 변수 없음): `register.cpp`가 `registry.engine.setProperty(kTileSourceProperty, QVariant::fromValue<QObject*>(&tileSource(service)))`, 이어서 `QObject::connect(&tileSource(service), &QObject::destroyed, &registry.engine, [e = &registry.engine] { e->setProperty(kTileSourceProperty, QVariant()); })`(끌 때 MapService가 지도 창보다 먼저 죽는다). geoservice 안에서 `TileSource`는 언제나 `QPointer`로 든다.
- 지도·엔진·fetcher·답·캐시는 모두 GUI 스레드다. 타일 그림 풀기(JPEG/PNG, 타일당 약 0.4 ms)도 Qt Location이 GUI 스레드에서 한다(바꾸지 않음, §10).

#### 5.6.8 궤적·영역 받기·서비스
- `TrailBook`(QObject, `MapService::Private` 소유): `VehicleRegistry`의 기체(처음 있는 것과 `vehicleAdded`)마다 `positionChanged`를 듣고 `appendTrailPoint(목록, {latDeg, lonDeg}, settings::trailMinMeters(), settings::trailMaxPoints())`가 참이면 `pointAdded(int sysid, QGeoCoordinate coordinate)`(위치 없음·(0, 0)은 `appendTrailPoint`가 거른다). `vehicleRemoved`면 그 궤적을 버린다. `settings::onTrailMaxPointsChanged`면 모든 궤적에서 넘는 점을 앞에서 지운다(신호 없음; `TrailLayer`가 같은 규칙으로 스스로 지운다). `clear()`는 모두 비우고 `cleared()`. `QList<QGeoCoordinate> trailOf(int sysid) const`.
- `MapDownloadJob`(QObject, `Job`을 **가진다** — 하위 클래스 아님, SitlDownload 선례): 생성자 `MapDownloadJob(TileSource& source, settings::MapType type, QString language, QGeoRectangle area, int minZoom, int maxZoom, qint64 total, QObject* parent)`, 안에서 `job_ = new Job(OperationKind::MapDownload, this)`. `Job* job() const`, `void start()`.
  - `start`: `job_->setStep(QT_TRANSLATE_NOOP("Job", "타일 받는 중"))`(JobView가 문맥 "Job"으로 그림), `setCancellable(true)`, `setProgress(0)`, INFO `DownloadStarted` "Map download started: <total> tiles".
  - 확대가 작은 것부터, 그 안에서 행(y) 오름차순, 열 i 순서(§5.6.3의 x 규칙)로 `source.fetch(type, language, z, x, y, true, …)`를 동시에 `kDownloadParallel`개까지. 콜백마다 끝난 수를 세고, 오류(`TileFailed` 포함)도 센다. `setProgress(double(done) / total)`.
  - `cancelRequested`: 새 요청을 멈추고 열린 표를 모두 `source.cancel`, `finishCancelled()`(글은 공용 "취소했어요."), INFO `DownloadCancelled` "Map download cancelled: <done> of <total> tiles". 이미 저장한 것은 남는다.
  - 다 끝나면 INFO `DownloadFinished` "Map download finished: <total> tiles, <failed> failed". 실패 0이면 `succeed()`, 아니면 `fail(make(MapError::TileFailed), QCoreApplication::translate("Map", QT_TRANSLATE_NOOP("Map", "타일 %1개를 받지 못했어요")).arg(failed))`.
- `MapService`(pimpl; `struct MapService::Private`는 `internal/MapServicePrivate.h`, 정의는 `internal/MapService.cpp`). 생성자: TileStore 스레드(§5.6.5); `TileSource(http, *store, tileHost, this)`; `source->setLanguage(translator.language())`와 `Translator::languageChanged` → `source->setLanguage(translator.language())`; `TileSource::languageChanged` → `languageChanged`; `TrailBook::pointAdded`·`cleared` → `trailPointAdded`·`trailsCleared`; `TileStore::sized`·`cleared`·`failed` → `storeSizeReady`·`storeCleared`·`storeFailed`.
  - 저장소 고장: `Private::storeBroken`(처음 거짓)은 `TileStore::failed`면 참, `sized`면 거짓.
  - `startDownload`: `planDownload` 오류를 그대로 돌려준다. `storeBroken`이면 `StoreFailed`(받아도 남지 않으므로). 지금 작업이 `Pending`·`Running`이면 `DownloadBusy`. 아니면 남은 `MapDownloadJob`을 `deleteLater`하고 지금 `mapType()`·`language()`로 새로 만들어 `start()`, `downloadChanged`. 작업의 `finished`에도 `downloadChanged`. 끝난 작업은 다음 `startDownload`나 `dismissDownload`(→ `deleteLater`, `downloadChanged`)까지 남는다(fcFlash 선례).
  - `requestStoreSize` → `TileStore::size`, `clearStore` → `TileStore::clear`, `clearTrails` → `TrailBook::clear`.

CanTakeOver 깃발을 두지 않아 다른 항목·핸들러가 쥔 누름을 가져가지 않는다.

- `PinchHandler { objectName: "mapPinch"; target: null; rotationAxis.enabled: false; grabPermissions: PointerHandler.TakeOverForbidden }` — 활성이 될 때 `startCentroid = map.toCoordinate(centroid.position, false)`, `onScaleChanged: (delta) => input.zoomAround(map.zoomLevel + Math.log2(delta), startCentroid, centroid.position)`.
