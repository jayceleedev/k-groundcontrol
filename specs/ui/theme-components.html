0.0.2 테마와 UI 부품 — 설계 그림

스펙 specs/features/0.0.2-theme.md(초안 4)의 그림이에요. 색 값은 제안이고, CSS 변수 이름은 스펙 §3.3 토큰과 같아요(지도 자리 무늬 = mapPatternA·B). 실제 화면은 Qt(QML)로 그려요.

1. 네 테마 — 틀(상단바·좌 메뉴·가운데·우 사이드바·하단바)

라이트·다크는 0.0.1처럼 나란히 놓여요. 에어로 두 개는 가운데(지도 자리)가 창 전체에 깔리고 바가 그 위에 반투명 유리로 겹쳐, 뒤의 지도 무늬가 흐리게 비쳐요.

2. UI 부품 목록 패널(갤러리)

좌 메뉴 맨 아래 "UI 부품 목록"을 누르면 나오는 패널의 내용이에요. 위 단추로 테마를 바꿔 보세요. 에어로에서는 카드 바탕이 유리가 돼요.
