# comm/mavlink (바탕 1층)
역할: 방언과 링크별 파싱 상태를 한 곳에 모아요.
수명: 전역 링크 관리 수명 안의 링크별 파서.
받는 것: 각 링크 워커의 수신 바이트.
주는 것: 방언과 메시지 메타타입의 입구 Mavlink.h, 완성 프레임만 내놓는 MavlinkParser::parse, dropV1NonHeartbeat.
기여: 없음.
의존: app/errors, Qt Core.
수신 복구: 손상 프레임의 끝에서 읽은 다음 시작 표식을 버리지 않고 새 프레임으로 이어가요.
안 하는 것: 화면 표시와 사용자 명령은 기능 모듈이 맡아요.
